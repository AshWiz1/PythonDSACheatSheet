# Python DSA Cheat Sheet

A quick reference guide for common Data Structures and Algorithms operations in Python.

## Overview

This cheat sheet provides concise syntax examples and method signatures for essential DSA concepts, useful for coding interviews and competitive programming.

## Contents

- **Collections**: Lists, Queues, Deques, Heaps, Sets, Dictionaries
- **Sorted Structures**: SortedList with bisect operations
- **String Operations**: Slicing, splitting, searching, case conversion
- **Array Operations**: Indexing, slicing, sorting, reversing
- **Binary Search**: Using `bisect` module for efficient searching
- **Math Utilities**: GCD, digit/alphabet validation

## Installation

Required dependencies:
```bash
pip install sortedcontainers
```

## Usage

Open `cheatSheet.py` to view syntax examples for each data structure and operation.
